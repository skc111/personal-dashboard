# 日常面板 · Personal Dashboard

把课程、记账、重要事项和每日回顾放在一个简洁的面板里。

**电脑本地使用 · 安卓独立运行 · 离线记录 · 可选坚果云同步**

[下载安装包](https://github.com/skc111/personal-dashboard/releases/latest) · [详细使用说明](docs/使用说明.md) · [反馈问题](https://github.com/skc111/personal-dashboard/issues)

> **这是程序分享，不是个人数据分享。** 仓库与下载包不包含作者的日程、账本、课程、备份或账号密码。新安装从空数据开始；每个人使用自己的同步账号。

## 先下载，再使用

普通使用者直接下载下面的安装包，**不需要克隆源码、安装 Node.js 或购买服务器**。

| 你的设备 | 下载入口 | 基本要求 |
| --- | --- | --- |
| Windows / macOS / Linux | [电脑版 ZIP](https://github.com/skc111/personal-dashboard/releases/download/v1.0.2/personal-dashboard-desktop-1.0.2.zip) | Python 3.10+；Windows 不需要 WSL |
| 安卓手机 | [安卓版 ZIP](https://github.com/skc111/personal-dashboard/releases/download/v1.0.2/personal-dashboard-android-1.0.2.zip) | Android 8.0+，较新的系统 WebView |

以上直链对应 v1.0.2；后续版本请到 [Releases](https://github.com/skc111/personal-dashboard/releases/latest) 查看。下载包附带第三方许可，`SHA256SUMS` 可用于校验文件完整性。

### Windows：双击启动

1. 安装 [Python 3.10 或更新版本](https://www.python.org/downloads/windows/)，确保可使用 `py` 或 `python` 命令。
2. **完整解压**电脑版 ZIP，进入包含 `launch.py` 的文件夹。
3. 双击 **`Start-Dashboard.cmd`**，等待浏览器自动打开。
4. 首次成功后，可以使用 **`Start-Dashboard.vbs`** 隐藏控制台启动。

想放到桌面：为 `Start-Dashboard.vbs` **创建快捷方式**，不要把 VBS 单独移出项目文件夹。若系统禁用 VBS，继续使用 CMD 即可。

### macOS / Linux：一条命令

安装 Python 3.10+，在解压后的项目文件夹中运行：

```bash
python3 launch.py
```

默认地址为 `http://127.0.0.1:8787`。启动器会等待本地服务就绪，再打开浏览器。

### 安卓：不依赖电脑

1. 解压安卓版 ZIP，安装里面的 **`personal-dashboard-1.0.2.apk`**。
2. 如果系统询问是否允许当前浏览器/文件管理器安装应用，按需允许。
3. 打开「日常面板」即可开始记录；不设置同步也能使用。

**电脑关机不影响安卓使用。** 卸载或清除应用数据前，务必先导出备份。

**从旧版升级：直接覆盖安装，不要先卸载。** 官方 v1.0.2 沿用 v1.0.0 / v1.0.1 的包名和签名，不改变记录目录、坚果云凭据或加密密钥标识；正常覆盖安装无需重新绑定。若手机提示签名不一致，请停止安装并反馈，不要清除数据。

v1.0.2 移除日程模块及首页相关待办入口，保留今日、课程、记账、DDL、回顾。旧日程只作为历史数据保留在原存储、完整导出和同步中，不再参与首页及新生成的回顾/周报；升级不删除旧记录。另补充电脑端仅保存在浏览器时的警告、紧急导出与关页提醒。

## 可以做什么

| 模块 | 主要功能 |
| --- | --- |
| 今日 | 收支、课程、近期 DDL 与当前时间一目了然 |
| 课程 | 每门课一张卡片，整理考试要求、知识点、问题与复习资料链接 |
| 记账 | 收入/支出、分类统计、日支出图、按城市分开的旅行账本、CSV 导出 |
| 重要事项 | 截止日期与时间、完成状态、首页 DDL 提醒 |
| 回顾与周报 | 生成并编辑每日回顾，查看每周统计 |

另有深色模式、JSON 备份与合并导入，以及可选的跨设备同步。

## 手机与电脑怎么同步

使用**自己的坚果云账号**提供 WebDAV 存储，不需要部署服务器。

1. 在坚果云创建第三方**应用密码**，不要填写登录密码。[官方教程](https://help.jianguoyun.com/?p=2064)
2. 电脑打开右上角「仅本地」，或「设置 → 多设备同步」，填写邮箱与应用密码。
3. 手机填写**相同账号、相同同步文件夹**；两端可以分别创建应用密码。
4. 等待显示「已同步」，用一条测试记录确认双向更新。

有旧记录时，先让旧设备同步成功，再连接新设备。

- **前台约每 15 秒检查一次**，不是每次输入都即时推送。
- 离线先保存，联网后再合并；后台/锁屏不保证同步，重新打开会补同步。
- 不同记录自动合并；同一记录的并发修改保留多个版本，提示核对。
- 坚果云免费版有流量与请求频率限制，以服务商当前规则为准。

> **朋友一定要用自己的账号。** 共用同一个账号和同步文件夹，会把彼此的记录合并。同步内容目前没有端到端加密，不要公开分享云目录。

## 数据在哪里，如何备份

| 内容 | 保存位置 / 方式 |
| --- | --- |
| 电脑记录 | 运行后才创建的 `data/db.json` |
| 电脑自动备份 | `data/backups/`，修改前保留备份 |
| 电脑同步凭据 | 本地 `data/sync-config.json`，不包含在网页 JSON 导出中 |
| 浏览器离线缓存 | 当前浏览器的 IndexedDB |
| 安卓记录与凭据 | 应用私有目录；凭据由 Android Keystore 加密 |
| 开启同步后的副本 | 你自己的坚果云同步文件夹 |

程序没有作者运营的后台，个人记录不会自动上传到这个 GitHub 仓库。电脑上的凭据文件仍需妥善保护。

**建议定期使用「导出 JSON」或「导出完整备份」**，保存到私密位置。不要把运行后的整个项目目录发给朋友。

- 导入默认是**合并**，不是清空替换，也不是整库回滚。
- 升级电脑程序前先导出，保留原来的 `data/`，只更换程序文件。
- 安卓优先覆盖安装，不要为升级先卸载；不同签名的 APK 不能直接覆盖。
- 清除浏览器/应用数据前，先确认已同步并导出备份。
- 电脑网页离线时，新增修改可能只保存在浏览器。出现红色保存提示时，请先启动电脑服务或点击提示中的「立即导出备份」，再关闭页面。
- 一份同步文件最多 15MB；资料链接对应的附件不自动下载或同步。

完整说明见 [使用、同步与备份](docs/使用说明.md)。

## 常见问题

**Windows 双击没有反应？** 先运行 `Start-Dashboard.cmd` 查看报错，确认 Python 版本；VBS 可能被系统策略禁用。

**提示端口占用？** 启动器不会结束其他程序。换一个端口启动：

```bash
python launch.py --port 8790
```

同一份数据尽量固定使用同一个网址和浏览器。macOS / Linux 可把命令里的 `python` 换成 `python3`。

**关闭网页后服务还在？** 启动器会让本地服务在后台继续运行。想手动控制退出，可使用 `python server.py` 前台运行，结束时按 Ctrl+C。

**能用 GitHub Pages 打开，或把 Python 服务直接暴露到公网吗？** 不建议。电脑版依赖本地 Python 后端，GitHub Pages 不能替代它；本服务按本机使用设计，不要直接公开端口。

**同步失败？** 检查应用密码、两端文件夹、网络与服务商额度。先保留本地记录并导出备份，不要通过卸载、清空数据来重试。

## 开发与维护

前端为原生 HTML / CSS / JavaScript；电脑后端仅使用 Python 标准库；安卓使用 Java + 本地 WebView。

**开发、日常使用和 Git 管理共用一个项目目录。** 修改后提交、推送源码即可；运行时 `data/`、备份、同步凭据与安卓签名密钥留在本地，不进入仓库。首次克隆后运行 `git config core.hooksPath .githooks` 开启提交检查，日常更新步骤见 [安全发布说明](docs/发布说明.md)。GitHub Release 安装包需要另行打包发布，不会随推送自动更新。

```text
static/             网页界面与同步逻辑
server.py           本地 HTTP 服务
sync_bridge.py      电脑端坚果云桥接
launch.py           跨平台启动器
android/            安卓源码与构建脚本，不含签名私钥
tests/              虚构数据回归测试
tools/              发布文件白名单、隐私检查与打包工具
docs/               使用与安全发布说明
```

普通使用者无需运行下面的命令。开发者可执行：

```bash
python3 -m unittest discover -s tests -p 'test_*.py'
node tests/sync-core.test.js

# 可选：浏览器回归测试，使用临时空库和随机端口
npm ci
npx playwright install chromium
npm run test:browser
```
