# 使用、同步与备份

## 先从本地开始

下载并完整解压发布包。电脑安装 Python 3.10+，运行 `Start-Dashboard.cmd`（Windows）或 `python3 launch.py`（其他系统）。没有数据时正常显示空列表，不会自动导入作者的内容。

日常模块在侧边栏/手机底栏；新增课程、记账和 DDL 后保存。DDL 截止时间可直接填小时与分钟；备注支持换行。日程模块已停用，已有日程仍保存在完整备份和同步数据中，不会因升级而删除。

示例数据按钮只会按需生成代码里的虚构演示条目，不是任何人的实际记录。

## 设置跨设备同步

1. 注册自己的坚果云账号。
2. 坚果云网页版「账户信息 → 安全选项 → 第三方应用管理」创建应用密码。
3. 电脑与手机的「多设备同步」填写相同邮箱，文件夹保持一致。应用密码可以分别创建。
4. 先等有旧记录的设备同步成功，再连接新设备。正常情况下新设备会合并现有内容，不以空库替换旧库。

**只在同一个人的设备之间共用同步账号。** 给朋友的是程序，不是自己的账号、应用密码、导出 JSON 或整个运行目录。

## 看懂同步状态

- **仅本地**：未启用同步；本机仍可记录。
- **待同步**：尚未上传，或遇到网络、凭据、额度问题；点进去看说明。
- **已同步**：最近一次同步完成。后台/锁屏后需打开应用补同步。
- **需要核对**：同一条记录被两端同时修改。全部版本都保留；统计暂显示其中一版。处理前建议导出完整备份。

普通不同记录会自动合并；删除保留删除标记，避免旧设备把已删除条目带回来。不要手动删除云目录内的设备快照。

## 备份、换设备、升级

- 「设置 → 导出 JSON」或「同步 → 导出完整备份」会包含全部记录与同步信息，文件请私密保管。
- 记账页可导出 CSV。
- 安卓导出使用系统文件保存窗口。卸载会删除未同步的本地记录，不能依靠重装解决同步失败。
- 升级 APK 尽量覆盖安装、不要先卸载；自行重新签名的 APK 无法覆盖官方分享包。
- 电脑升级前先导出；保留原来的 `data/`，只更换程序文件。不要把旧的运行目录上传到 GitHub。
- 导入为“合并”，不是整库回滚；旧同步备份不会自动撤销已确认的删除/更新。

## 常见问题

**Windows 双击没有反应**：改用 `Start-Dashboard.cmd` 查看报错，确认安装了 Python 3.10+。VBS 可能被系统策略禁用，CMD 仍可用。

**端口占用**：启动器不会结束其他程序。运行 `python launch.py --port 8790`；同一份数据尽量固定使用同一个网址和浏览器。

**退出网页后 Python 仍运行**：隐藏启动器会让本地服务继续在后台工作；这是正常的。想随窗口关闭服务，可用 `python server.py` 前台启动，再按 Ctrl+C。

**邮箱/应用密码错误**：使用第三方应用密码而不是坚果云登录密码。不要把密码写进 Issues 或截图。

**请求过多或额度不足**：服务商限制不由应用控制；等待重试或额度恢复。请勿连续点击同步。

**离线时无法重新打开电脑网页**：首次加载网页仍需本地 Python 服务。安卓的界面已打包进 APK，不依赖电脑。

**资料链接无法打开**：同步保存的是链接和文本，链接指向的在线附件仍需网络及相应访问权限。
